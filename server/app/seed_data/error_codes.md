# Appliance error codes

## Error code E24 (washing machines)
E24 means the drain pump is blocked or the drain hose is kinked. Switch the machine off, check that the hose is not bent, and clean the pump filter behind the small door at the bottom front. If E24 comes back, book an engineer visit.

## Error code F05 (dishwashers)
F05 means the dishwasher cannot fill with water. Check that the water tap under the sink is fully open and that the inlet hose is not bent. If F05 comes back, book an engineer visit.
