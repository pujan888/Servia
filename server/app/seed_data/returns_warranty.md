# Returns and Warranty

## Return an appliance
You can return an appliance within 30 days of delivery if it is unused and in its original packaging. We collect it free of charge. The refund goes back to the original payment method within 5 working days of collection.

## Return a used or damaged appliance
A used appliance can only be returned if it is faulty. Report the fault first. An engineer confirms the fault before a return is arranged.

## Warranty cover
Every appliance has a 2-year manufacturer warranty from the delivery date. It covers parts and labour for faults. It does not cover accidental damage, such as dropping the appliance, or misuse, or cosmetic marks. Engineer visits that are not covered cost £49 for the call-out.

## Extended warranty
The warranty cannot be extended after purchase. For cover after 2 years, join the Northwind Care Plan.
